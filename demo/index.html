03 / Across the whole set

A pattern, or
one good example?

Each estimate is a within-frame contrast, averaged across 12 frames. Intervals resample whole frames. No single sentence stands in for the experiment.

Each plot has its own symmetric scale around zero. Dots are frame effects; the line is the 95% bootstrap interval. These intervals describe a small authored set, not all English.

04 / A result worth questioning

Negation in the wrong place
can still be a powerful cue.

In the first DistilGPT-2 run, embedded “no” favored “ever” more than matrix “no” did—the reverse of the intended structural prediction. Is it proximity, an alternative parse, or something about these materials? The raw conditions make that question inspectable.
